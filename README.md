# Моделирование работы морского порта

Консольный backend на C++20 моделирует работу порта в течение месяца: расписание и
фактические прибытия судов, сезонную погоду, динамические очереди, разгрузку тремя
типами кранов, уход судов, рейтинг, доходы и штрафы. Отдельный режим подбирает
экономически выгодное количество кранов с учётом их покупки.

## Сборка и запуск

Требуются CMake 3.20 или новее и компилятор с поддержкой C++20.

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
```

Режимы запуска:

```bash
./build/sea_port                 # интерактивная настройка каждого дня
./build/sea_port --auto          # полностью случайный месяц
./build/sea_port --optimize      # экономический подбор количества кранов
./build/sea_port --auto --seed 7 # воспроизводимый сценарий
```

В интерактивном режиме сначала выбираются сезон, краны, вместимость ожидания,
разгрузочные места и шаг вывода. Для каждого дня можно выбрать погоду и добавить
ручные либо случайные заявки на срок до семи дней вперёд.

## Основные правила

- Сухогрузы перевозят зерно, танкеры — нефть, контейнеровозы — контейнеры.
- Каждому грузу соответствует собственный тип крана и очередь.
- Разгрузка начинается только при наличии крана и подходящего разгрузочного места.
- Погода изменяет дневную производительность кранов; волны уровня 5 останавливают их.
- Дорогие заявки имеют приоритет, но длительное ожидание и близкий уход повышают
  приоритет дешёвого судна и предотвращают его бесконечное вытеснение.
- За немедленное обслуживание начисляется 12% бонуса. Долгое ожидание уменьшает
  начисление вплоть до 55% базовой стоимости.
- За каждый день сверх плановой стоянки вычитается настраиваемый штраф.

Начальная стоимость кранов:

| Тип | Стоимость, у.е. |
|---|---:|
| Для сыпучих грузов | 600 000 |
| Для жидких грузов | 900 000 |
| Контейнерный | 1 200 000 |

Все значения находятся в `SimulationConfig` и могут быть изменены вызывающим кодом.
