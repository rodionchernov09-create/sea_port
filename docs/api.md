# Публичный API

Все типы находятся в пространстве имён `sea_port`.

## `SimulationConfig`

Хранит длительность и шаг, сезон, число кранов и мест, вместимость ожидания, диапазоны
случайных отклонений, штрафы, параметры генерации, критерии качества, цены кранов и
`random_seed`.

## `PortSimulation`

- `ScheduleShip(spec)` — регистрирует ручную заявку и возвращает идентификатор.
- `SetWeather(day, weather)` — задаёт погоду конкретного будущего дня.
- `GenerateRandomParametersForDay(day, horizon)` — создаёт погоду и заявки на период
  от одного до семи дней.
- `SimulateDay()` — выполняет следующий день и возвращает `DailyReport`.
- `RunRandomMonth()` — запускает полностью случайный оставшийся месяц.
- `Finalize()` — фиксирует число незавершённых судов; повторный вызов безопасен.
- `statistics()` — предоставляет итоговую статистику только для чтения.
- `CranePurchaseCost()` — возвращает цену выбранного парка кранов.

Дни должны обрабатываться последовательно. После `Finalize()` новые заявки и дни не
принимаются.

## `ShipSpec`

Описывает тип, название, день регистрации и планового прибытия, массу, срок стоянки и
терпение. `actual_arrival_day` и `unloading_delay_days` необязательны: при отсутствии
они генерируются случайно.

## `CraneOptimizer`

`Optimize(config, options)` перебирает количества от одного до заданного максимума.
Возвращает все результаты, отсортированные по прибыли после покупки, и выбранный
вариант. Каждый результат содержит стоимость, операционную прибыль, прибыль после
покупки, рейтинг, долю обслуживания и срок окупаемости.

## `Statistics`

Предоставляет количества прибывших, разгруженных, ушедших, непринятых и незавершённых
судов; средние и максимальные очередь, ожидание и задержку; начисления, штрафы,
операционную прибыль и подробные `CompletionRecord` по каждой разгрузке.
