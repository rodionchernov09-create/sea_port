# Правила симуляции

## Погода

Вероятности волн зависят от сезона. Зимой уровни 3–5 встречаются чаще, летом чаще
уровни 0–1. Уровень волн преобразуется в коэффициент работы:

| Волны | 0 | 1 | 2 | 3 | 4 | 5 |
|---:|---:|---:|---:|---:|---:|---:|
| Работоспособность | 100% | 94% | 82% | 62% | 32% | 0% |

Дневной объём равен базовой производительности крана, умноженной на этот коэффициент.
Базовые производительности: 1800 тонн для сыпучего, 2400 для жидкого и 1200 для
контейнерного груза.

## Случайное расписание

Число заявок на день с удалённостью `d` генерируется распределением Пуассона:

```text
lambda(d) = current_day_arrival_rate * exp(-future_arrival_decay * d)
```

Горизонт ограничен семью днями. Вероятности типов равны 58% для сухогрузов, 27% для
танкеров и 15% для дорогих контейнеровозов. Фактическое прибытие отличается от
планового на равномерную случайную величину из диапазона конфигурации. При создании
заявки в ходе месяца прибытие не может оказаться раньше дня её регистрации.

## Приоритет и справедливость

Обычная часть приоритета:

```text
стоимость груза + дни ожидания * waiting_priority_bonus
```

При остатке терпения не более одного дня добавляется критический приоритет. После
`fairness_wait_days` добавляется ещё более высокий приоритет старой заявки. Поэтому
дорогие корабли выгоднее в обычной ситуации, но дешёвые не могут голодать бесконечно.

## Финансы

Базовые ставки за тонну: зерно — 45, нефть — 80, контейнеры — 110 у.е.

Множитель оплаты:

- ожидание 0 дней: 1,12;
- ожидание 1 день: 1,06;
- далее уменьшение на 0,04 за день;
- нижняя граница: 0,55.

```text
начисление = масса * ставка * множитель
штраф = сверхплановые дни в порту * penalty_per_extra_day
операционная прибыль = начисление - штраф
результат после покупки = операционная прибыль - стоимость кранов
```

Окупаемость в месяцах равна стоимости кранов, делённой на среднюю положительную
месячную операционную прибыль.

## Оптимизатор

Для каждой комбинации выполняется несколько прогонов. Во всех комбинациях применяются
одинаковые начальные `seed`, поэтому внешние сценарии сопоставимы. Разгрузочные места
не увеличиваются автоматически: это самостоятельное ограничение порта.

Основной результат — максимальная средняя прибыль после вычета покупки. Вариант
помечается допустимым только при достижении минимального рейтинга и доли обслуживания.
Если ни один вариант не допустим, программа всё равно показывает лучший финансовый
результат и явно сообщает о нарушении ограничений.
